L命题与逻辑

数学的语言：什么叫命题、怎样判断真假、怎样证明。几何证明与线代推导都靠它。

L1

命题与真假

能判断真假的陈述句，才叫命题。

必会

  • 命题 = 可以判断真假的陈述句
  • 真命题 / 假命题的判断
  • 疑问句、祈使句、感叹句都不是命题
  • 推翻一个全称命题，只需举一个反例

陷阱

  • 「π 是无理数吗？」不是命题（疑问句无法判真假）
  • 含未知数的开句（如 x>3）真假不定，不是命题

自测（先想，再看答案）

1判断「对顶角相等」是不是命题

答案：是命题，且是真命题

它是陈述句，并且可以判断真假——对顶角一定相等，所以是真命题。

2「请把门关上」是命题吗？

答案：不是

祈使句没有真假可言，不构成命题。只有能判断真假的陈述句才是命题。

L2

命题的条件与结论

每个命题都能写成「如果 p，那么 q」。

必会

  • p 是条件，q 是结论
  • 把普通语句改写为「如果……那么……」的形式
  • 改写时需要补全省略的部分

陷阱

  • 条件与结论找反（尤其句子语序颠倒时）
  • 有的命题要先补全主语才能看出条件

自测（先想，再看答案）

1把「两直线平行，同位角相等」写成如果……那么……

答案：如果两直线平行，那么同位角相等

前半句是条件 p，后半句是结论 q。写成标准形式后才能研究它的逆命题。

L3

四种命题与逆否等价

原命题与逆否命题同真同假——这是反证法的地基。

必会

  • 逆命题：交换条件与结论（若 q 则 p）
  • 否命题：条件结论同时否定（若 ¬p 则 ¬q）
  • 逆否命题：交换后同时否定（若 ¬q 则 ¬p）
  • 原命题 ⇔ 逆否命题（同真同假）；原命题真不代表逆命题真

陷阱

  • 默认逆命题也成立——这是最常见的逻辑错误
  • 把否命题与逆否命题搞混（否命题不与原命题等价）

自测（先想，再看答案）

1写出「若 a=0，则 ab=0」的逆否命题

答案：若 ab≠0，则 a≠0

先交换再同时否定。它与原命题同真同假，故也是真命题。补一句：它的逆命题「若 ab=0 则 a=0」是假的。

L4

逻辑联结词与真值表

且、或、非是三个运算，复合命题的真假可算出来。

必会

  • p∧q（且）：两者都真才真
  • p∨q（或）：至少一个真就真
  • ¬p（非）：真假相反
  • 德摩根律：¬(p∧q) = (¬p)∨(¬q)；¬(p∨q) = (¬p)∧(¬q)

陷阱

  • 把 ¬(p∧q) 当成 (¬p)∧(¬q)——两者不同，这是最高频错误
  • 「或」在数学里是「至少一个」，不是「二选一」

自测（先想，再看答案）

1p 真、q 假，求 ¬(p∧q) 与 (¬p)∧(¬q) 的值

答案：前者为真，后者为假

p∧q = 假，故 ¬(p∧q) = 真；而 (¬p)∧(¬q) = 假∧真 = 假。两者不等——这就是德摩根律要表达的。

L5

充分条件、必要条件与充要条件

p⇒q 的一句话翻译。

必会

  • p 是 q 的充分条件：有 p 就够推出 q（p⇒q）
  • p 是 q 的必要条件：要 q 必须有 p（q⇒p）
  • 充要条件：p⇔q（互相都能推出）
  • 用集合判断：小集合能推出大集合（范围小的推范围大的）

陷阱

  • 充分与必要的方向说反
  • 把「充分不必要」与「必要不充分」混淆

自测（先想，再看答案）

1x>3 是 x>1 的什么条件？

答案：充分不必要条件

x>3 一定满足 x>1（充分）；但 x>1 不一定 x>3（不必要）。范围小 ⇒ 充分。

L6

证明的方法与书写

每一步都要有依据——这就是证明。

必会

  • 证明的格式：已知 → 求证 → 证明
  • 综合法：由已知一步一步推向结论（由因导果）
  • 反证法三步：反设（假设结论不成立）→ 归谬（推出矛盾）→ 结论（原命题成立）
  • 证伪只需一个反例

陷阱

  • 举几个例子就当成证明了全称命题（特殊不能代替一般）
  • 循环论证——把要证的结论当条件用
  • 反证法归谬之后忘了回到原结论

自测（先想，再看答案）

1证明「√2 是无理数」应该用什么方法？

答案：反证法

假设 √2 是有理数，设 √2 = p/q（最简分数），推出 p、q 都是偶数与最简矛盾，故假设不成立。

L7

数学归纳法

两步完成对无限多个情形的验证。

必会

  • 第一步奠基：验证 n = 1（或起始值）时命题成立
  • 第二步递推：假设 n = k 成立，证明 n = k+1 也成立
  • 两步缺一不可

陷阱

  • 只验证 n=1,2,3 就下结论（没有递推就不是证明）
  • 递推时没用到归纳假设

自测（先想，再看答案）

1用归纳法证明 1+2+…+n = n(n+1)/2，第一步做什么？

答案：验证 n=1 时成立

左边 = 1，右边 = 1×2/2 = 1，等式成立。这就是奠基步；之后再做递推。

A数与式

计算的地基。后续所有内容都是它的组合。

A1

有理数与数轴

数轴上一个点 = 一个数。符号规则是全部计算的地基。

必会

  • 数轴三要素：原点、正方向、单位长度
  • 相反数、绝对值的意义与求法
  • 有理数四则运算的符号法则
  • 乘方意义与运算顺序（先乘方、再乘除、后加减）

陷阱

  • −2² = −4（负号不在括号内，不参与乘方）
  • 括号前是负号时，去括号各项都要变号

自测（先想，再看答案）

1计算 −2² + (−3)×2

答案：−10

先乘方：−2²=−4；再乘法：(−3)×2=−6；最后相加：−4+(−6)=−10。

2求 |−5| − |3|

答案：2

绝对值先去符号：5−3=2，顺序不能颠倒。

A2

实数与二次根式

有理数不够用，补上无理数；开方与平方互逆。

必会

  • 平方根、算术平方根、立方根的区别
  • √a 有意义的条件：a ≥ 0
  • √(a²) = |a|（必须先取绝对值）
  • 最简二次根式与分母有理化

陷阱

  • √16 = 4，不是 ±4（√ 只表示算术平方根）
  • √(a²) 直接写成 a 是错的，必须写 |a|

自测（先想，再看答案）

1化简 √48

答案：4√3

48 = 16×3，√16 = 4，故 4√3。先提最大平方因子。

2计算 √((−7)²)

答案：7

√(a²) = |a|，所以等于 |−7| = 7。

A3

整式运算

字母当作数，同类项才可合并。

必会

  • 幂的四条法则：aᵐ·aⁿ=aᵐ⁺ⁿ、(aᵐ)ⁿ=aᵐⁿ、(ab)ⁿ=aⁿbⁿ、aᵐ÷aⁿ=aᵐ⁻ⁿ
  • 单项式×多项式、多项式×多项式
  • 合并同类项：字母与指数都相同

陷阱

  • a²·a³ = a⁵（不是 a⁶）；(a²)³ = a⁶
  • 同底数幂相乘指数相加，幂的乘方指数相乘——别混

自测（先想，再看答案）

1计算 x² · x³

答案：x⁵

同底数幂相乘，指数相加：2+3 = 5。

2计算 (2a²b)³

答案：8a⁶b³

积的乘方：系数 2³ = 8，各字母指数分别乘 3。

A4

乘法公式

两个必须背到条件反射的恒等式。

必会

  • 平方差：(a+b)(a−b) = a² − b²
  • 完全平方：(a±b)² = a² ± 2ab + b²
  • 公式的逆用（用于因式分解与配方）

陷阱

  • 完全平方最容易漏中间项 2ab
  • (a+b)² ≠ a² + b²

自测（先想，再看答案）

1展开 (3x+2)(3x−2)

答案：9x²−4

符合平方差 (a+b)(a−b)，a=3x、b=2，直接得 a²−b²。

2展开 (x−5)²

答案：x²−10x+25

完全平方 a²−2ab+b² = x² − 2·x·5 + 25。

A5

因式分解

把「和」变成「积」——解方程的关键一步。

必会

  • 顺序：提公因式 → 公式法 → 十字相乘
  • 分解必须彻底（直到不能再分）
  • 检验方法：把结果乘回去

陷阱

  • 分解不彻底，如 x⁴−1 只写到 (x²+1)(x²−1) 就停
  • x²+4 在实数范围内无法分解，别硬拆

自测（先想，再看答案）

1分解 x²−6x+9

答案：(x−3)²

首尾是平方、中间是 −2ab 型，直接套完全平方公式。

2分解 2x²−8

答案：2(x+2)(x−2)

先提公因式 2，再对 x²−4 用平方差。

A6

分式

除法写成分数形式，分母永远不能为零。

必会

  • 分式有意义的条件：分母 ≠ 0
  • 约分、通分（最简公分母）
  • 分式四则运算
  • 分式方程去分母后必须验根

陷阱

  • 约分只能约「因式」，不能直接约掉加减项
  • 去分母产生的增根必须舍去

自测（先想，再看答案）

1化简 (x²−4)/(x+2)

答案：x−2（x≠−2）

分子用平方差分解为 (x+2)(x−2)，约去 (x+2)。别忘写 x≠−2。

A7

不等式与不等式组

解集是一个范围，用数轴表达最清楚。

必会

  • 两边同乘（除）负数，不等号方向要改变
  • 解集在数轴上表示：实心点含端点、空心点不含
  • 不等式组取公共部分（交集）

陷阱

  • 乘除负数忘变号——最高频错误
  • 「无解」也是合法答案（如 x>3 且 x<1）

自测（先想，再看答案）

1解不等式 −2x > 6

答案：x < −3

两边同除 −2 并变号：x < −3。步骤：移项 → 系数化 1（除负数要变号）。

B方程与不等式

把条件写成等式/不等式再解出来。

B1

一元一次方程

等式两边同做同一种运算，等式仍成立。

必会

  • 解方程五步：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1
  • 移项必须变号

陷阱

  • 移项忘记变号
  • 去分母时漏乘不含分母的项

自测（先想，再看答案）

1解方程 3x − 5 = 7

答案：x = 4

移项：3x = 7+5 = 12；系数化 1：x = 4。

B2

二元一次方程组

两个条件同时满足 = 两条直线的交点。

必会

  • 代入消元法：把一个未知数用另一个表示
  • 加减消元法：让某未知数系数相同后相减
  • 解必须同时满足两个方程

陷阱

  • 只解出一个未知数就停笔
  • 消元后回代时代入的不是原方程

自测（先想，再看答案）

1解方程组 x+y=5，x−y=1

答案：x=3, y=2

两式相加消去 y：2x=6 → x=3；回代 x+y=5 得 y=2。

B3

一元二次方程

含平方项的方程，最多两个实根。

必会

  • 三种解法：因式分解法、配方法、公式法
  • 判别式 Δ = b²−4ac：Δ>0 两根、Δ=0 一根、Δ<0 无实根
  • 韦达定理：x₁+x₂ = −b/a，x₁·x₂ = c/a

陷阱

  • 公式法漏除 2a（x = (−b±√Δ)/2a）
  • Δ<0 时仍强行求根

自测（先想，再看答案）

1解 x² − 5x + 6 = 0

答案：x = 2 或 x = 3

十字相乘得 (x−2)(x−3)=0。也可用 Δ = 25−24 = 1 代入公式。

2判断 x²+2x+5 = 0 的根的情况

答案：无实根

Δ = 4−20 = −16 < 0，无实数根。

B4

分式方程

去分母、求解、验根——三步缺一不可。

必会

  • 解法：去分母 → 解整式方程 → 代入最简公分母验根
  • 使最简公分母为 0 的根是增根，必须舍去

陷阱

  • 跳过验根直接给答案
  • 增根不是算错，是去分母带来的必然产物

自测（先想，再看答案）

1解 1/x + 1/(x−2) = 1

答案：x = 2±√2（需验根）

去分母乘 x(x−2)：(x−2)+x = x(x−2)，整理得 x²−4x+2=0，代入求根公式。

C函数

变化关系的图像语言——线性代数直觉的来源。

C1

平面直角坐标系

每个点有一个唯一地址 (x, y)。

必会

  • 四个象限内点的符号规律
  • 点的平移：右加左减、上加下减
  • 关于 x 轴 / y 轴 / 原点对称的坐标变化

陷阱

  • 坐标书写顺序颠倒 (x,y)
  • 对称时搞混哪个坐标变号

自测（先想，再看答案）

1点 (−3, 2) 关于 x 轴的对称点

答案：(−3, −2)

关于 x 轴对称：横坐标不变，纵坐标变号。

C2

一次函数

匀速变化的世界就是一条直线。

必会

  • y = kx + b：k 决定增减与倾斜，b 决定与 y 轴交点
  • k>0 递增、k<0 递减
  • 图像与 x 轴交点 = 对应方程的根
  • 两直线平行 ⇔ k 相等

陷阱

  • k<0 时误以为斜率大就上升
  • 求与 x 轴交点应令 y=0（不是 x=0）

自测（先想，再看答案）

1求 y = 2x − 4 与 x 轴的交点

答案：(2, 0)

令 y=0：0 = 2x−4 → x = 2，交点 (2,0)。

C3

反比例函数

两量乘积固定，一个变大另一个就变小。

必会

  • y = k/x（k≠0），图像是双曲线（两支）
  • k>0 在一、三象限，k<0 在二、四象限
  • k 的几何意义：图像上一点向两轴作矩形的面积 = |k|

陷阱

  • 误认为整个双曲线都递减（要分两支讨论）
  • k 的几何意义与坐标符号混淆

自测（先想，再看答案）

1y = k/x 经过点 (2, 3)，求 k

答案：k = 6

把坐标代入：k = xy = 2×3 = 6。

C4

二次函数

抛物线的顶点就是最值——初中函数的顶点站。

必会

  • 一般式 y=ax²+bx+c；顶点式 y=a(x−h)²+k，顶点 (h, k)
  • 对称轴 x = −b/(2a)
  • 开口方向由 a 确定；与 x 轴交点个数由 Δ 确定
  • 二次函数与一元二次方程是同一件事的两种看法

陷阱

  • 顶点坐标符号写反（顶点式里是 x−h）
  • a>0 开口向上、有最小值（容易背反）

自测（先想，再看答案）

1求 y = x² − 4x + 3 的顶点

答案：(2, −1)

配方：y = (x−2)² − 1，顶点 (2,−1)。公式法：−b/2a = 4/2 = 2。

D几何

空间与形状的推理。全等/相似/圆是主干。

D1

相交线与平行线

平行线的性质与判定是一对互逆命题。

必会

  • 对顶角相等、邻补角互补
  • 三线八角：同位角、内错角、同旁内角
  • 判定：同位角相等 / 内错角相等 / 同旁内角互补 → 平行
  • 性质：已知平行 → 上述角关系成立

陷阱

  • 把「判定」和「性质」的条件与结论用反
  • 只有两直线平行的前提下，这些角关系才成立

自测（先想，再看答案）

1两直线平行，同旁内角有什么关系

答案：互补（和为 180°）

平行线的性质：同旁内角互补。

D2

三角形基础与全等

形状大小完全相同的两个三角形。

必会

  • 内角和 180°；两边之和大于第三边
  • 全等五判定：SSS、SAS、ASA、AAS、HL（直角三角形专用）
  • 全等 → 对应边、对应角全部相等

陷阱

  • SSA（边边角）不能判定全等——经典陷阱
  • 写全等时对应顶点顺序要一一对应

自测（先想，再看答案）

1已知两边及其夹角，可用哪个判定

答案：SAS

两边夹一角 ⇒ SAS。注意必须是夹角。

D3

等腰与等边三角形

对称性带来的「三线合一」。

必会

  • 等边对等角、等角对等边
  • 三线合一：顶角平分线 = 底边中线 = 底边高
  • 等边三角形三边相等、三角各 60°

陷阱

  • 三线合一必须在等腰三角形中，且指顶角那一条
  • 底边上的高与腰上的高不是同一条

自测（先想，再看答案）

1等腰三角形顶角 40°，求底角

答案：70°

内角和 180°，两底角相等：(180−40)/2 = 70°。

D4

勾股定理

直角三角形专属的边长关系。

必会

  • a² + b² = c²（c 为斜边）
  • 逆定理：满足 a²+b²=c² → 该三角形是直角三角形
  • 特殊比例：30°-60°-90° 为 1:√3:2；45°-45°-90° 为 1:1:√2

陷阱

  • 把斜边当直角边代入
  • 只有直角三角形才能用

自测（先想，再看答案）

1直角边 3、4，求斜边

答案：5

3²+4² = 9+16 = 25，c = √25 = 5。

D5

相似三角形

形状相同、大小成比例。

必会

  • 判定：AA、SAS（两边成比例且夹角相等）、SSS（三边成比例）
  • 对应边成比例、对应角相等
  • 平行于三角形一边的直线截出的三角形与原三角形相似
  • 周长比 = 相似比，面积比 = 相似比的平方

陷阱

  • 对应边找错（顺序不对应）
  • 面积比忘记平方，直接写成相似比

自测（先想，再看答案）

1相似比 1:2 的两个三角形，面积比是多少

答案：1:4

面积比 = 相似比的平方 = 1²:2² = 1:4。

D6

四边形

平行四边形的判定是整章的枢纽。

必会

  • 平行四边形判定：两组对边分别平行 / 相等、对角线互相平分、一组对边平行且相等
  • 矩形 = 平行四边形 + 一个直角（对角线相等）
  • 菱形 = 平行四边形 + 一组邻边相等（对角线互相垂直）
  • 正方形 = 矩形 + 菱形

陷阱

  • 把「对角线相等」当成平行四边形的性质（那是矩形特有）
  • 判定条件混用

自测（先想，再看答案）

1对角线互相垂直平分的四边形是什么

答案：菱形

对角线互相平分 ⇒ 平行四边形；再加垂直 ⇒ 菱形。

D7

圆

到定点距离相等的点集；圆的定理都围绕「半径相等」展开。

必会

  • 垂径定理：垂直于弦的直径平分弦及弧
  • 圆心角 = 2× 同弧所对圆周角
  • 直径所对的圆周角 = 90°
  • 切线判定与性质：切线垂直于过切点的半径
  • 弧长 l = nπr/180，扇形面积 S = nπr²/360

陷阱

  • 同弧所对的圆周角与圆心角的倍数关系记反
  • 切线证明漏掉「过半径外端」这一条件

自测（先想，再看答案）

1直径所对的圆周角是多少度

答案：90°

半圆所对的圆周角是直角，这是圆中最常用的结论之一。

D8

图形变换与锐角三角函数

sin/cos/tan 是直角三角形里边的比值。

必会

  • 平移、旋转、轴对称的性质（对应线段相等、对应角相等）
  • sin A = 对边/斜边、cos A = 邻边/斜边、tan A = 对边/邻边
  • 特殊角：sin30°=1/2、sin45°=√2/2、sin60°=√3/2
  • 解直角三角形：已知一边一角或两边求其余

陷阱

  • tan 的分子分母记反
  • 特殊角函数值记串

自测（先想，再看答案）

1sin 30° = ?

答案：1/2

特殊角记忆：30°/45°/60° 的正弦依次为 1/2、√2/2、√3/2。

E统计与概率

数据的描述与不确定性的度量。

E1

统计量

用一个数概括一堆数据的中心与离散程度。

必会

  • 平均数、中位数、众数的意义与求法
  • 方差：衡量波动大小，越小越稳定
  • 中位数要先排序，偶数个取中间两个的平均

陷阱

  • 求中位数前忘记排序
  • 方差越小说明越稳定（容易背反）

自测（先想，再看答案）

1数据 1,2,3,4,5 的中位数

答案：3

已有序，5 个数的中位数是第 3 个。

E2

概率初步

古典概型：P = 有利结果数 / 总结果数。

必会

  • 必然事件 P=1、不可能事件 P=0
  • 列举所有等可能结果：列表法、树状图
  • 两步试验必须把所有组合列全

陷阱

  • 两步试验漏组合（如抛两次硬币漏掉顺序）
  • 把「至少一次」当成「恰好一次」

自测（先想，再看答案）

1抛两次硬币，两次都正面的概率

答案：1/4

总结果 4 种（正正/正反/反正/反反），有利 1 种，P = 1/4。
