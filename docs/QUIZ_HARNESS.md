# 学习与考试闭环

系统围绕学习者的目标、基础、作答和讨论证据形成路线，而不是固定课程目录。小学到研究生知识、论文与 PDF 都可以成为这一产品理念中的素材；论文/PDF 导入和 Agent 对话证据抽取是否可用，须分别验收，不能从本次题目评分功能推断已实现。

## 本次实现的测验契约

1. 出题后校验题型、数量、答案、选项、分值和评分点。单元题为4选择、1填空、1简答；每卷100分。与历史题干做标准化及相似度查重，再以独立模型请求检查可作答性、参考答案与评分点的一致性。最多重试3次；校验失败不发布题目、不覆盖旧轮次。
2. 简答题出题时固定评分点及整数分值，各评分点合计等于该题分值。填空题固定可接受答案；数值文字、有限小数和分数等价由程序比较。没有匹配到预设答案时不得由模型任意加分。
3. 提交答案必须带服务端资料键和题目轮次。后端从已保存的题目取分值与标准，忽略客户端提供的题目或总分。选择题、填空题与参考答案一致时由程序得分；空答0分。简答题模型只判定固定评分点是否满足并引用学生原文，程序按满足项累加。
4. 总分等于逐题得分之和，60分通过。模型的 `score`、`pass`、额外评分点及虚构作答证据均不予采纳。原样提交参考答案必须100分。
5. 题目按 `rounds` 追加，包含题目、参考答案、评分点、验题状态、历次作答、逐题得分和依据。同轮相同作答重复提交返回同一成绩，避免重试产生不同分数。换题不覆盖旧轮次；普通状态保存不能改写已签发轮次与成绩。
6. 旧题首次使用时建立历史轮次并验题；无法恢复升级前已经丢失的题目或作答。旧的总分没有逐题得分时界面明确显示未记录，不能凭总分反推。

## 答题工作区

完整题目只在原生大弹窗展示，卡片显示题集数量、最近成绩和入口。上一套/下一套保留每套独立草稿；综合测验按来源学习地图归集旧卷。题内提供预设评分标准，提交后显示逐题分数和判分理由；历次提交只读，再做本套建立独立草稿。

每次输入先保存到本机恢复区，400毫秒后同步服务端；关闭、翻页、页面隐藏和重新联网时刷新待保存内容。服务端确认后清除本机待同步副本。同一标签页的乱序请求不能覆盖较新草稿。同步失败明确保留本机草稿并提供重试；不声称支持浏览器存储被清理后的离线恢复或多人同时编辑冲突合并。

## 学习反馈

综合测验读取单元最近作答、历史错题（每单元最近12条）和“需复习”标记；新的综合测验另存一份，保留原卷。细化按服务端最新路线追加，补救单元继承原单元前置依赖，不要求先通过失败单元。

Agent 自由对话中的临时题目尚未自动转成结构化测验记录。模型验题和简答题语义判断仍属于模型证据，不是数学证明；本契约保证流程、依据、数据保存和计分可审计，不宣称模型永不判断错误。

## 回归

```sh
python3 -m unittest discover -s tests -v
node tests/test_frontend_regressions.js
python3 learning-path/gen_path_page.py
node --check learning-path/path_app.js
```

所有回归使用临时或独立 E2E 状态目录。发布时同时更新 `study_assistant.py` 与 `quiz_harness.py`，前端重新生成。生产数据迁移是读取时兼容升级，不扫描或重写整个学习库。
