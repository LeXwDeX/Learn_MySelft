# 出题题型结构：4 选择题 + 1 填空题 + 1 简答题（设计文档）

## Goal
学习路径的每次出题（`/path/node` 首次生成 + `/path/requiz` 换新题）统一为固定结构：**共 6 题 = 前 4 题选择题 + 第 5 题填空题 + 第 6 题简答题**。
前端：选择题渲染为**可点选选项**（A/B/C/D 单选）；填空/简答保持文本作答。判分适配各题型（选择题按字母比对、填空题按语义等价、简答题按评分要点）。旧材料（无 options 的旧题）自动回退原文本作答方式（向后兼容）。

## 数据契约（新）
```json
{"type":"choice","q":"题干","options":["选项1","选项2","选项3","选项4"],"answer":"A","explain":"解析"}
{"type":"fill","q":"题干","answer":"参考答案（多种表述用 ｜ 分隔）","explain":"解析"}
{"type":"short","q":"题干","answer":"评分要点","explain":"解析"}
```
- 兼容：无 options / 无 type 的旧题照常工作（前端：无 options → 文本作答；服务端判分：未标注 type → 按简答/文本题处理）。

    """归一单道自测题：透传 type/options（有 options 一律视为选择题）；题干为空返回 None。"""
    question = clip(q.get("q") or q.get("question"), 1500)
    if not question:
        return None
    item = {"q": question, "answer": clip(q.get("answer"), 1500),
            "explain": clip(q.get("explain"), 1500)}
    opts = []
    if isinstance(q.get("options"), list):
        opts = [clip(str(o), 400) for o in q.get("options") if str(o).strip()][:4]
    if opts:
        item["options"] = opts
        item["type"] = "choice"
    else:
        t = q.get("type") if isinstance(q.get("type"), str) else ""
        if t in ("fill", "short"):
            item["type"] = t
    return item

```js
  // ---------- 自测题渲染（选择题点选 / 填空·简答文本作答） ----------
  var choiceAns = {};   // { 题号: 字母 } —— 选择题当前选择
  function quizQHtml(q, i, radioPrefix, areaPrefix, cur) {
    var head = '<div class="quiz-box"><p class="q">' + (i + 1) + '. ' + mdRender(q.q) + '</p>';
    if (q.options && q.options.length) {
      var opts = q.options.map(function (o, j) {
        var letter = String.fromCharCode(65 + j);
        var checked = choiceAns[i] === letter ? ' checked' : '';
        return '<label class="qopt"><input type="radio" name="' + radioPrefix + i + '" value="' + letter + '"' + checked + '>' +
          '<span>' + letter + '. ' + mdRender(o) + '</span></label>';
      }).join('');
      return head + '<div class="qopts">' + opts + '</div></div>';
    }
    return head + '<textarea id="' + areaPrefix + i + '" placeholder="写下你的答案…">' + (cur != null ? esc(cur) : '') + '</textarea></div>';
  }
  function choiceChange(e) {
    var t = e.target;
    if (!t || t.type !== 'radio') return;
    var m = (t.name || '').match(/^(opt|qmo)-(\d+)$/);
    if (m) choiceAns[+m[2]] = t.value;
  }
  function syncChoiceRadios() {
    var ins = document.querySelectorAll('#panel-body input[type=radio]');
    for (var i = 0; i < ins.length; i++) {
      var m = (ins[i].name || '').match(/^opt-(\d+)$/);
      if (m && choiceAns[+m[1]] != null) ins[i].checked = (ins[i].value === choiceAns[+m[1]]);
    }
  }
```
