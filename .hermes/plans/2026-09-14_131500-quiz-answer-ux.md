# 设计：自测答题体验升级 — 答题框加大 + 「放大答题」模态框

- 日期：2026-09-14
- 项目：自学社 / 学习路径页（learning-path）
- 目标文件：`learning-path/path_app.js`、`learning-path/path_template.html`（+ 运行生成器产出 `learning-path.html`）

## Goal（一句话）
学习路径页自测答题体验升级：① 内嵌答案输入框由 66px 高加大到 140px 并随输入自动扩展；② 新增「放大答题」模态框——大空间答题，支持写回内嵌框，并可一键提交。

## 架构说明（看懂再动手）
这是「生成器 + 单文件产物」架构：`python3 gen_path_page.py` 把 `path_app.js` 的内容替换进 `path_template.html` 的占位符，生成最终 `learning-path.html`（由 Hermes 部署到服务器）。**只改源文件，产物用生成器生成，不要手工编辑 learning-path.html。**
- 页面不保存任何本地数据（无 localStorage）；答案只在 DOM 中，提交时经既有 `submitQuiz()` 读 `#ans-{i}` 的 value 上调后端。本次改动**不新增任何存储**、不改后端、不改数据流。
- 约束：桌面专用（页面最低宽 1360px）、无 CDN、UI 与全站一致（按钮统一用现有 `.btn` / `.btn.primary` 类，颜色用 CSS 变量 `--accent` `--rule` `--soft` `--paper2` `--serif` `--mono` 等）。

### Task 2 — path_app.js：逻辑
2.1 在小工具区（`function storeKey()` 附近）新增 `bindAutoGrow(el)`：
```js
// 答案框自动扩展：随输入增高（以 CSS min-height 为下限）
function bindAutoGrow(el) {
  if (!el || el.__ag) return;
  el.__ag = true;
  var fit = function () {
    el.style.height = 'auto';
    var mh = parseFloat(window.getComputedStyle(el).minHeight) || 140;
    el.style.height = Math.max(el.scrollHeight, mh) + 'px';
  };
  el.addEventListener('input', fit);
  fit();
}
```

2.4 新增模态框逻辑函数（放在 renderNodeDetail 之后、submitQuiz 之前，风格保持一致）：
```js
// ---------- 放大答题（模态框） ----------
var modalNodeId = null;
function openQuizModal(id) {
  var n = nodeById(id), d = state.nodeDetail[id];
  if (!n || !d) return;
  modalNodeId = id;
  $('qm-title').textContent = 'NODE ' + id + ' · ' + n.title + ' — 自测答题';
  var qs = (d.quiz && d.quiz.questions) || [];
  var h = qs.map(function (q, i) {
    var cur = $('ans-' + i) ? $('ans-' + i).value : '';
    return '<div class="quiz-box"><p class="q">' + (i + 1) + '. ' + esc(q.q) + '</p>' +
      '<textarea id="qma-' + i + '" placeholder="写下你的答案…">' + esc(cur) + '</textarea></div>';
  }).join('');
  $('qm-body').innerHTML = h;
  renderMathIn($('qm-body'));
  qs.forEach(function (q, i) { bindAutoGrow($('qma-' + i)); });
  $('quiz-modal').hidden = false;
}
function closeQuizModal(saveBack) {
  if (saveBack && modalNodeId != null) {
    var qs = (((state.nodeDetail[modalNodeId] || {}).quiz) || {}).questions || [];
    qs.forEach(function (q, i) {
      var src = $('qma-' + i), dst = $('ans-' + i);
      if (src && dst) dst.value = src.value;
    });
  }
  $('quiz-modal').hidden = true;
  modalNodeId = null;
}
function submitQuizFromModal() {
  var id = modalNodeId;
  closeQuizModal(true);
  if (id != null) submitQuiz(id);
}
```
2.5 在 boot() 的既有绑定区（`$('backend-label').textContent = API;` 前后均可）绑定一次（全局）：
